## COLOR MIXER
## ABOUT 
Color Mixer is acolor-matching game where players choose two colors to create the target color. they earn points for each correct answers and must answer before the timer runs out

##How to play 
1. click the start button to begin the game
2. A target color will apper in the middle
3. choose 2 colors that can be mixed to crate the target color
4. if your answer correct you get 100 point
5. if your answer is wrong you can try again
6. you have 10 seconds to answer
7. when the time runs out the game ends and the score reset


## Game conditions :
1.choose 2 colors to match the target
2.correct answer=+100 points
3.wrong answer= no point 
4.you have 10 sec per round
5. Game ends when the timer reaches 0
6. The same color won't apper twice in a row
